# 机器人 CSV 工具：学习地图

## 一句话理解

数据沿着这条管线移动：

```text
CSV 文本
  -> CsvReader
  -> vector<Sample>
  -> RobotAnalyzer
  -> AnalysisResult
  -> JsonWriter
  -> JSON 文本
```

三个命令行程序只是这条管线的三个观察窗口：

1. `read_robot_csv`：只观察“CSV 是否成功变成 C++ 数据”。
2. `analyze_robot_csv`：继续观察“位置是否成功变成速度、加速度和统计量”。
3. `export_robot_json`：跑完整条管线并生成 JSON 文件。

## 语言功能对应在哪里

| 要求 | 项目中的作用 | 代码位置 |
|---|---|---|
| `struct` | 表示一条数据记录 | `include/RobotTypes.hpp` |
| `class` | 封装读取、分析、输出行为 | `CsvReader`、`RobotAnalyzer`、`JsonWriter`、`Stopwatch` |
| `vector` | 保存数量运行时才知道的样本 | `vector<Sample>`、`vector<TimedVector>` |
| 文件输入 | `ifstream` 读取 CSV | `src/CsvReader.cpp` |
| 文件输出 | `ofstream` 写 JSON | `src/JsonWriter.cpp` |
| `chrono` | 使用单调时钟测量耗时 | `include/Stopwatch.hpp` |
| CMake | 描述源文件怎样变成库、程序和测试 | `CMakeLists.txt` |
| 单元测试 | 用已知运动验证数值和错误处理 | `tests/robot_tests.cpp` |

## 为什么同时使用 struct 和 class

`struct` 主要回答“数据长什么样”：

```cpp
struct Sample {
    double time_seconds;
    Vector3 position;
};
```

`class` 主要回答“谁负责做这件事”：

```cpp
class CsvReader {
public:
    std::vector<Sample> read(const std::string& filename) const;
};
```

在 C++ 语言层面，`struct` 和 `class` 非常相似；最明显的默认区别是
`struct` 成员默认 `public`，`class` 成员默认 `private`。本项目采用的是工程语义：
简单记录用 `struct`，有职责和接口的组件用 `class`。

## 数学到代码的映射

相邻位置样本给出一个速度样本：

```text
dt = t[i+1] - t[i]
vx = (x[i+1] - x[i]) / dt
```

相邻速度样本给出一个加速度样本：

```text
dt = velocity_time[i+1] - velocity_time[i]
ax = (vx[i+1] - vx[i]) / dt
```

三维向量大小：

```text
magnitude = sqrt(x*x + y*y + z*z)
```

总体方差：

```text
mean = sum(values) / N
variance = sum((value - mean)^2) / N
```

因此，`N` 个位置样本会产生 `N-1` 个速度样本和 `N-2` 个加速度样本。

## CMake 在做什么

`robot_core` 是公共库，包含读取、计算和输出逻辑。三个 `add_executable` 分别创建三个
命令行程序，再用 `target_link_libraries` 把公共库连接进去。测试程序也连接同一个库，
所以测试验证的是生产程序真正使用的算法，而不是复制出来的另一份算法。

```text
CsvReader.cpp ─┐
Analyzer.cpp  ─┼─> robot_core ─┬─> read_robot_csv
JsonWriter.cpp ┘               ├─> analyze_robot_csv
                               ├─> export_robot_json
                               └─> robot_tests
```

## 单元测试在证明什么

测试数据采用 `x=t^2`，时间点为 `0,1,2,3`：

- 相邻差分速度是 `1,3,5`。
- 速度均值是 `3`。
- 速度总体方差是 `8/3`。
- 再次差分得到加速度 `2,2`。
- 加速度均值是 `2`，方差是 `0`。

测试还确认重复时间会被拒绝，否则算法将发生除以零。

## 推荐练习顺序

1. 在 `read_robot_csv.cpp` 中逐行打印所有位置，理解 `vector` 遍历。
2. 给 `known_motion.csv` 的 `y` 列设计一个简单函数，手算后修改测试期望值。
3. 把总体方差的除数从 `N` 改成样本方差的 `N-1`，观察哪个测试失败。
4. 故意写两个相同时间，观察异常如何从类传到 `main`。
5. 给 JSON 增加 `duration_seconds` 字段，并给它补测试。
