# Dataset provenance

- `documents.json` and `queries.json`: original fictional SDK text and manually authored retrieval labels, created for this repository on 2026-10-15. No employer documents, real device specifications, customer data, or course assignment solutions are included.
- P01 telemetry is generated by `ai_path/experiment.py`. Device IDs, operating conditions, faults, and measurements are simulated. Device-level splitting checks a software property; it does not establish transfer to physical robots.
- `inference-fixture.jsonl`: hand-constructed timestamps for validating metric formulas. `measurement_origin=fixture` is mandatory. These are not GPU or model performance observations.
- The English lexical query set is deliberately small and partly shares words with the documents. It is a development/regression fixture, not an independent production-quality benchmark. Create a separately collected, frozen holdout set before making retrieval quality claims.
- P05 uses the repository's fictional documents as a tiny language-model smoke corpus. Training and validation are separated by document; the corpus is too small for capability claims.

All files in this directory were authored independently for this curriculum. See `../LICENSE` and `../SOURCES.md`.
